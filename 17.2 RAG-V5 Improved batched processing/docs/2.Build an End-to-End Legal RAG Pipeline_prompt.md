## 4. `# 4 - Per-page classification: digital vs scanned vs hybrid`

## 5. `# 5 - Layout parsing & OCR (local only)`

- If `is_scanned` or hybrid: run local OCR model on each page; produce page-level text, bounding boxes, OCR confidence.

- Save OCR/text outputs to local disk and store `text_hash` in `document_versions`.
- Log OCR summary metric `ocr_conf_doc` (mean/median). If `ocr_conf_doc` below threshold, write warning to `pipeline_logs` and optionally flag `status = 'needs_review'` but **do not** proceed to embeddings unless explicitly allowed by policy (by default stop and log).

## 6. `# 6 - Noise removal & normalization`

- Normalize whitespace, unicode, ligatures.
- Save normalized text and update `text_hash`.
- Document exact regex & rules used (as code comments) for reproducibility.

## 7. `# 7 - Structure detection: sections, articles, tables`

- Detect headings, section / article numbers (e.g., `Section 12`, `Article 43(1)`), and tables.
- Produce a `sections` JSON structure with offsets, title, and section_id.
- Detect `has_tables` and extract tables into a structured format (CSV / JSON).
- Store `has_amendments` boolean via regex/LLM-based detection (LLM must be local or offline; otherwise use robust regex). If LLM is required, call local LLM instance and log cost/time.

## 8. `# 8 - Metadata extraction & canonical fields`

- Extract the recommended metadata fields (table below).
- Upsert document-level metadata into `documents` and `document_versions` rows.
- Validate `jurisdiction` is set to `Kenya` (or parsed).
- Populate `ocr_conf_doc`, `page_count`, `is_scanned`, `has_tables`, `has_amendments`, `superseded_by` appropriately.

> ### Recommended relational schema (create-if-not-exists)

```sql
-- documents
CREATE TABLE IF NOT EXISTS documents (
  doc_id TEXT PRIMARY KEY,
  short_title TEXT,
  citation TEXT,
  jurisdiction TEXT,
  doc_type TEXT
);

-- document_versions
CREATE TABLE IF NOT EXISTS document_versions (
  version_id TEXT PRIMARY KEY,
  doc_id TEXT REFERENCES documents(doc_id),
  file_hash TEXT,
  text_hash TEXT,
  shingle_hash TEXT,
  document_date DATE,
  version_info TEXT,
  status TEXT CHECK (status IN ('current','superseded','draft')),
  superseded_by TEXT NULL,
  ocr_conf_doc REAL,
  page_count INT,
  is_scanned BOOLEAN,
  has_tables BOOLEAN,
  has_amendments BOOLEAN
);

-- embeddings
CREATE TABLE IF NOT EXISTS embeddings (
  chunk_id TEXT PRIMARY KEY,
  version_id TEXT REFERENCES document_versions(version_id),
  chunk_text TEXT,
  embedding_vector VECTOR,  -- pgvector column
  chunk_type TEXT,
  section_ref TEXT,
  extra_metadata JSONB
);

-- ingest_errors
CREATE TABLE IF NOT EXISTS ingest_errors (
  id SERIAL PRIMARY KEY,
  version_id TEXT,
  step TEXT,
  error_message TEXT,
  error_payload JSONB,
  occurred_at TIMESTAMP DEFAULT now()
);

-- pipeline_logs
CREATE TABLE IF NOT EXISTS pipeline_logs (
  id SERIAL PRIMARY KEY,
  version_id TEXT,
  event TEXT,
  payload JSONB,
  logged_at TIMESTAMP DEFAULT now()
);
```

## 9. `# 9 - Chunking strategy (hierarchy-aware)`

- Use detected `sections`/`articles` as primary boundaries.
- For each section:

  - Split into paragraph-level chunks without breaking subsection numbering.
  - Aim for 400–800 tokens per chunk.
  - Assign chunk IDs using canonical pattern: `<doc_shortname>:<section_id>` or `constitution_2010:art.43(1-3)`.

- Store `chunk_id`, `chunk_text`, `chunk_type`, and `section_ref`.
- Produce a summary table of chunks (pandas DataFrame) and save to disk & DB.

## 10. `# 10 - Embedding generation & pgvector upsert`

- Use a local embedding model (specify model path).
- Device-aware inference; batch for performance.
- Generate vector for each chunk; upsert to `embeddings` table (pgvector).
- On success log `✅ Upserted N embeddings for version_id=<version>`.
- If an upsert fails, log to `ingest_errors` and stop.

## 11. `# 11 - Versioning & deduplication`

- Compute `shingle_hash` or similarity signatures for text to detect duplicates.
- If a new version is identical or near-identical to an existing `current` version, mark new `document_versions.status = 'superseded'` and set `superseded_by`.
- Prefer `status = 'current'` rows for retriever/filtering.
- Ensure `version_info`, `document_date` fields are populated.

## 12. `# 12 - QA, logging, monitoring`

- Create QA checks:

  - Page count sanity
  - `ocr_conf_doc` threshold
  - chunk coverage (% of document text chunked)
  - embedding dims & null checks

- Write QA report to `pipeline_logs` and save JSON to disk.
- Expose metrics for monitoring (JSON + DB writes).
- Emit `✅ Pipeline complete` when all checks pass.
- If any QA check fails, insert into `ingest_errors` and stop.
